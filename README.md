# ALFakePlayer

适用于 Paper / Folia 的假人插件。玩家可以购买并召唤自己的假人，让它在原地挖矿、打怪、放方块，背包满了自动往箱子里卸货。假人是服务端里真实的玩家实体，行为遵循原版规则；也支持多个子服共用数据，跨服管理和召回假人。

## 功能

- **购买与召唤**：购买可以要求金币、点券、物品，或几种同时要求。假人分 Normal / Pro / Pro Max 三个等级，运行的区块范围（默认 3×3 / 5×5 / 7×7）和召唤价格各不相同，都可以配置。
- **自动工作**：挖掘正前方的方块（快捷栏第 3~9 格放了方块或作物时只挖同类），用锄头收割成熟的农作物，自动攻击（可调攻击间隔；可以对着盔甲架挥剑，用横扫刷怪），放置方块并自动补货（主手拿着工具时放在副手），自动种植（树苗、作物等种在正前方一格），自动钓鱼（尽量平视抛向正前方的水，按原版钓鱼，不受 CustomFishing 等钓鱼插件影响），背包满时向相邻箱子卸货，饿了自动进食。卸货时保留快捷栏、副手、装备和一份备用食物；主背包满了就不再捡东西，不会塞满快捷栏；有人打开它的背包时暂停卸货。
- **背包与设置**：随时打开假人背包，未召唤或死亡时也能打开，支持 Shift 快速放入和取出；可以设置工作方向、是否会被推动、是否保持蹲下。
- **防刷物品**：背包界面里显示的是副本，每次操作都以假人背包的实际内容为准，先扣除再给出，改动立即存盘；副本或菜单图标被其他插件、漏洞带出界面时会被自动删除。
- **领地兼容**：在 Dominion、Residence 的领地里，假人和主人的权限相同：主人自己的领地和主人有权限的领地都能干活，不用单独添加假人；其他领地插件可在配置中加入。
- **传送**：传送到假人身边，或把假人叫到自己身边，可以跨世界。
- **重启后自动召唤**：正常关服时在运行的假人，开服后在原位置召唤回来，不收费，可以在配置中关闭。
- **跨服**：多个子服连接同一个 MySQL，在任意子服都能管理自己的假人、传送过去或召回到当前子服；可选用 Redis 让跨服操作即时生效。
- **菜单可自定义**：所有菜单的布局和文字都能修改，图标支持资源包 CustomModelData、CraftEngine 和 ItemsAdder 物品。
- **显示**：假人在 TAB 列表中显示 LuckPerms 前缀和 PlaceholderAPI 称号；跨服时，其他子服的 TAB 也能看到它。
- **TAB 测试假人**：`/afp test <数量>` 让自带名字表里的虚拟玩家陆续进入 TAB（服务端没有实体，不占性能），计入在线人数变量和服务器列表人数。每个名字有固定的 UUID、权限组和性格，会定时有人下线、有人上线，显示和真人一样的进服、退服提示。
- **测试假人聊天**：测试假人会在聊天区说话：回复真人、欢迎进服的人、冷场时互相闲聊。所有发言排队发出，限流随在线人数和聊天热度自动调整；有概率几个人一窝蜂地抢着说（几个人一起欢迎、一起回“在”），像真人群聊一样。可以接入 AI（默认 DeepSeek，任何 OpenAI 格式的接口或 Claude 都行），也可以交给服务器的聊天插件排版和转发，看起来和真人发言一样。
- **其他**：内置中文和英文；插件更新时配置文件自动升级，自定义内容保留，原文件会备份。

## 运行环境

- Paper 或 Folia 26.1.2 及以上，Java 25。已在 Folia 26.1.2、26.2、26.3 上验证，不支持 Spigot。
- 可选插件：

| 插件 | 用途 |
| --- | --- |
| Vault + 任意经济插件 | 用金币购买和召唤 |
| PlayerPoints | 用点券购买 |
| LuckPerms | 给假人设置权限组，在 TAB 中显示前缀 |
| PlaceholderAPI | 在 TAB 中显示称号；提供在线人数变量 |
| CraftEngine / ItemsAdder | 菜单图标使用自定义物品 |
| EasyBot | 群里查询在线玩家时，列表里也有本服的假人和 TAB 测试假人（`config.yml` 的 `easybot`） |

## 安装

1. 把 `ALFakePlayer-1.0.5.jar` 放进 `plugins/`，重启服务器。
2. 首次启动会在 `plugins/ALFakePlayer/` 下生成 `config.yml`、`database.yml`、`menus/` 和 `lang/`。
3. 召唤假人默认要扣金币，需要安装 Vault 和经济插件。不想收费的话，在 `config.yml` 中设置 `economy.enabled: false`。

主指令 `/alfakeplayer`，简写 `/afp`。

| --- | --- |
| `/afp` | 打开主菜单，购买、召唤和管理假人 |
| `/afp spawn [编号] [normal\|pro\|promax]` | 在自己的位置召唤假人 |
| `/afp despawn [编号]` | 收回假人，背包和设置保留 |
| `/afp list` | 查看自己的假人 |
| `/afp b <编号>` | 打开假人背包 |
| `/afp dir <编号>` | 让假人面向自己当前看的方向 |
| `/afp rename <编号> <名字>` | 给假人改名，消耗一张改名卡 |
| `/afp delete <编号>` | 永久删除假人和它的背包 |
| `/afp tp <编号>` | 传送到假人身边 |
| `/afp tph <编号>` | 把假人传送到自己身边 |

主菜单中点击假人头像：

| 操作 | 说明 |
| --- | --- |
| 左键 | 未召唤时选择等级召唤；已召唤（包括在其他子服）时打开召回确认 |
| 右键 | 传送到假人身边，假人在其他子服时把你送过去 |
| Shift+左键 | 收回已召唤的假人（支持跨服），背包和设置保留 |
| Shift+右键 | 打开假人背包 |

**管理员**（在后台输入时不用加 `/`）

| 指令 | 说明 |
| --- | --- |
| `/afp admin help` | 查看管理员指令 |
| `/afp grant <玩家> <数量>` | 给玩家增加假人 |
| `/afp set <玩家> <总数>` | 把玩家的假人补到指定数量 |
| `/afp card <玩家> [数量]` | 发放改名卡 |
| `/afp items` | 设置购买假人需要的物品（只能在游戏内用） |
| `/afp b <玩家> <编号>` | 打开任意玩家假人的背包，可以取放物品（只能在游戏内用） |
| `/afp atp <名字>` 或 `/afp atp <玩家> <编号>` | 传送到任意玩家的假人，假人在其他子服时把你送过去，没有等待和冷却（只能在游戏内用） |
| `/afp despawn <名字>` | 收回任意玩家的假人 |
| `/afp delete <名字>` | 永久删除任意玩家的假人 |
| `/afp clear [服务器ID\|all]` | 收回本服、指定子服或全部子服的所有假人（10 秒内输入两次才执行） |
| `/afp servers` | 查看各子服状态和假人数量 |
| `/afp reload` | 重载 `config.yml`、菜单和语言文件，本服已召唤的假人会暂时收回，再在原位置召唤回来 |
| `/afp test <数量>` / `/afp test stop` | 设定 TAB 测试假人的人数，它们在一两分钟内陆续进出；`stop` 立即全部清除（只是 TAB 条目；跨服时其他子服也能看到，计入在线变量） |
| `/afp test info <名字>` / `/afp test group <名字> <组>` | 查看测试假人的档案（权限组、性格、会不会说话），或修改它固定的权限组 |
| `/afp test say <名字> <内容>` | 让某个测试假人立即说一句 |
| `/afp test chat` | 查看测试假人聊天的发送方式、排队和限流情况、AI 用量和上次的错误 |
| `/afp test ai` | 向 AI 接口发一个测试请求，确认地址、Key 和模型可用 |

## 变量

需要安装 PlaceholderAPI。

| 变量 | 说明 |
| --- | --- |
| `%alfakeplayer_online%` | 全服在线：所有子服的真实玩家 + 所有子服的假人 |
| `%alfakeplayer_fake%` | 全服假人数 |
| `%alfakeplayer_server_online%` | 本服在线：本服真实玩家 + 本服假人 |
| `%alfakeplayer_server_fake%` | 本服假人数 |

这里的假人包括已召唤的假人和 `/afp test` 添加的虚拟玩家。变量结果每秒更新一次。

- 单服时，全服变量就是本服的数量。
- 跨服时只统计装了本插件、连接同一个数据库的子服；其他子服的数字每次心跳更新一次（`database.yml` 的 `sync.heartbeat_seconds`，默认 10 秒）。
- 假人不会加入服务器的在线玩家列表，所以 `/list`、`%server_online%` 不算假人，也不占 `max-players` 名额。要显示含假人的在线人数，请用上面的变量。
- 服务器列表里的人数：直接连接子服时会加上本服的假人；通过 BungeeCord / Velocity 时由代理端统计，本插件改变不了。

## 配置

| 文件 | 内容 |
| --- | --- |
| `config.yml` | 服务器 ID、语言、假人数量上限、购买和召唤价格、领地插件、等级范围、传送、性能 |
| `database.yml` | 数据库（默认 SQLite，跨服用 MySQL）和 Redis |
| `menus/*.yml` | 各个菜单的布局、图标和文字 |
| `tab_test.yml` | TAB 测试假人的名字表、权限组比例、陆续进出和进服退服提示 |
| `tab_chat.yml` | 测试假人聊天：发送方式（接入聊天插件）、限流、关键词回复、语料、冷场对话和 AI |
| `lang/*.yml` | 中文和英文消息 |

每个配置文件里都有详细注释。改完后执行 `/afp reload` 即可生效；`database.yml`、`server_id` 和 `server_name` 需要重启服务器。

菜单图标的写法：

```yaml
type: DIAMOND                       # 原版物品
custom_model_data: 10001            # 资源包模型
craftengine: "namespace:item_id"    # CraftEngine 物品
itemsadder: "namespace:item_id"     # ItemsAdder 物品
# 也可以写成 type: "ce:namespace:item_id" 或 type: "ia:namespace:item_id"
```

找不到自定义物品时显示 `type` 中的原版物品。

## 跨服设置

1. 每个子服在 `config.yml` 中设置不同的 `server_id`，要和 BungeeCord / Velocity 配置里的子服名一致。
2. 每个子服在 `database.yml` 中设置 `type: mysql`，连接同一个数据库，`prefix` 保持一致。
3. 推荐所有子服开启 `redis.enabled`，并使用相同的 `channel`，这样跨服操作即时生效；不开 Redis 也能用，大约延迟 1 秒。
4. Velocity 需要保持 `bungee-plugin-message-channel = true`（默认就是开启的）。

同一个假人同一时间只会在一个子服运行，换服不会复制物品。

跨服时，其他子服正在运行的假人和 `/afp test` 添加的虚拟玩家也会显示在本服的 TAB 列表中（假人带前缀和称号），大约 1 秒内同步；某个子服关服或失联后，它的条目会自动移除。

## 更新内容

### 1.0.5

新增

- **一窝蜂**：测试假人有概率几个人几乎同时说话，像真人群聊一样：关键词回复（有人问“有人吗”，三四个人一起回“在”“有”“咋了”）、真人进服时一起欢迎、测试假人进服打招呼和下线道别时一起回应、冷场对话你一句我一句很快说完。每人说不同的话，后面几句不等句间间隔、不看冷却。`tab_chat.yml` 的 `limits.burst` 设置概率（默认 25%）、人数（默认 3～4 人）和间隔；被 @ 的回复、真人之间正在聊天时不会一窝蜂。
- **AI 聊天更像真人**：提示词重写，给模型示范国内玩家的打字习惯（短、不加句号、随手打、少叫名字、不客服腔），并告诉它现在几点、每个测试假人正在游戏里做什么（`ai.activities`，每人每 30～60 分钟换一件）。自带梗表（`ai.memes`，网络梗和 MC 梗），每次随机挑 15 个给 AI，大概每三四句有一句带梗。一窝蜂时直接让 AI 给出三四个人各不相同的抢答。AI 回复里带上自己名字、整句加引号、句末句号的会自动去掉，和最近重复的话不发。新增 `ai.timezone`（默认 `Asia/Shanghai`）。
- **EasyBot 兼容**：装了 EasyBot（QQ 群服互通）时，群里查询本服在线玩家，列表里也有本服召唤的假人和 TAB 测试假人，和真人一样（带皮肤）。`config.yml` 的 `easybot` 可以关闭，或只列其中一种。

修复

- 装了 TrChat 等聊天插件时测试假人不说话：
  - 代理频道（如 TrChat 的 `Global`）要通过发言人的连接转发给代理端，测试假人没有连接，消息发不出去；现在借一个在线真人的连接发出去。
  - 频道的发言权限、格式条件现在按测试假人在 LuckPerms 里的权限组判断，和同组的真人一样；聊天格式里的 `%player_world%`、`%player_ping%` 等变量也有值了。
  - 交给聊天插件后 2 秒内本服没有真人收到这句话时，改按 `tab_chat.yml` 的 `format` 发出，并在后台提示一次原因，不会再悄悄没了。
  - 游戏里用 `/afp test say` 时报错（`AsyncPlayerChatEvent may only be triggered asynchronously`），之后所有测试假人的话都改成按 `format` 发，直到 `/afp reload`。
- 测试假人说话太少：默认限流放宽（每分钟 5 句起、每多一个真人多 1 句、最多 15 句，句间间隔 4～10 秒，同一个人 90 秒后可以再主动开口，一半的测试假人会说话，冷场 40～120 秒开话题）。已有的 `tab_chat.yml` 不会自动改，觉得话少时参照新的默认值调大 `limits` 和 `talkative_percent`。
- `tab_chat.yml` 的 `format` 和 `tab_test.yml` 的进退服提示格式不认 PlaceholderAPI 变量（如 `%luckperms_suffix%` 原样显示）。现在任何插件的变量都能用，按这个测试假人解析，和真人一样；变量返回的 `§` 颜色和 `&#RRGGBB` 十六进制颜色都能显示，消息内容里的 `%` 不会被当成变量。

升级须知

- 配置、菜单和语言文件的 `config_version` 不再跟随插件版本号，改回每个文件自己的整数，现在全部是 `1`，以后哪个文件有改动就单独加一，插件据此自动升级（改过的值保留，没改过的默认值换成新默认值，新选项自动加上，原文件备份到 `config-backups/`）。
- 1.0.4 写出的 `config_version: '1.0.4'` 第一次启动 1.0.5 时自动改成 `1`，只改这一行，其他内容和写法不变。
- 已有的文件不会自动补上 1.0.5 新增的选项：`config.yml` 的 `easybot`，`tab_chat.yml` 的 `limits.burst`、`ai.timezone`、`ai.activities`、`ai.memes`（从 1.0.3 及更早版本升级时还有 1.0.4 新增的 `config.yml` 的 `skins` 和 `tab_chat.yml` 的 `cross_server`）。这些选项缺少时按默认值生效，需要修改时参照插件自带的文件手动加上。

### 1.0.4

新增

- **假人皮肤**：召唤的假人和 TAB 测试假人随机套上正版皮肤，同一个假人一直是同一个皮肤，皮肤外层（头发、帽子、外套等）全部显示。皮肤从 `config.yml` 的 `skins.names` 里挑，留空时用 `tab_test.yml` 的名字表，没有正版账号的名字自动跳过。装了 SkinsRestorer 时通过它获取（用它的缓存和代理设置，名单里还可以填皮肤图片链接），没装时直接从 Mojang 获取；获取到的皮肤保存在 `skin-cache.yml`，之后不再联网。召唤时最多等 4 秒皮肤，没等到先用默认皮肤，下次召唤换上；TAB 测试假人获取到后立即换上。
- **测试假人跨服聊天**：`database.yml` 用 mysql 时，全网的测试假人和真人在同一个聊天里。任何子服的真人说话、进服，测试假人都会回应，从别的子服换过来的不算进服；话从测试假人所在的子服说出来，所有子服都能看到。适用于所有聊天插件：聊天插件已经把这句话跨服转发过来的，本插件不再补发，没转发的由本插件按 `format` 补发（`tab_chat.yml` 的 `cross_server.forwarded`，默认自动判断）。各子服聊天本来不互通时，设置 `cross_server.enabled: false`，测试假人只在自己的子服聊天。`/afp test chat` 显示由哪个子服安排聊天。

修复

- `tab_test.yml` 的 `groups` 用带点的组名（如 `lv.1`）时读取失败。
- 其他插件处理假人的交互、挖掘、放置、钓鱼、进食事件时报错（例如 GuibindPro 的空指针，因为假人不触发进服事件），不再每挖一下刷一次屏，每个插件只在后台提示一次。

升级须知

- 配置文件的 `config_version` 改为跟随插件版本号（`'1.0.4'`）。第一次启动 1.0.4 时，所有配置、菜单和语言文件自动升级：改过的值保留，没改过的默认值换成新默认值，新选项自动加上，原文件备份到 `config-backups/`。`tab_test.yml` 的 `groups` 改过时整段保留，不会把 `default` 组加回来。
- 升级后的文件由插件重新写出，列表会变成每项一行的写法，内容不变。

### 1.0.3

新增

- **TAB 测试假人**：
  - 自带 200 个像国内玩家的名字（拼音、英文、数字混搭），在 `tab_test.yml` 里可以改；上限从 80 提到 200。不会选中在线真人、真实假人、其他子服的测试假人和来过本服的玩家用过的名字；有真人用同名进服时，测试假人悄悄换人。
  - 每个名字有固定档案，存在数据库里，跨服共用：UUID（原版默认皮肤因此固定）、按 `groups` 比例抽中的权限组（TAB 里显示这个组的前缀）。组被删掉或在 LuckPerms 里不存在时，按比例重新抽一个；`/afp test group` 可以手动改。
  - 不再一下子全部出现：在 `join.ramp_up_seconds` 内陆续进出，之后每隔几分钟有一部分人下线、一部分人上线，显示和真人一样的进服、退服提示（`join.messages`，可改格式）。
- **测试假人聊天**（`tab_chat.yml`）：
  - 关键词回复（有人吗、你好、晚安、卡不卡、求带等 23 类）、被 @ 或叫到名字时回复、真人进服时欢迎、测试假人进服打招呼和下线前道别、冷场时一个人说一句或几个人聊一段（30 段对话），自带约 150 句日常对话。会说话的只占一部分（`talkative_percent`），其余潜水，被 @ 才回。
  - 所有发言进同一个队列，带打字时间和过期时间，一句一句发出。限流自适应：平时每分钟几句，在线真人越多、真人聊得越多，测试假人才说得越多，但最多占全部聊天的 40%；聊天热闹时句间间隔缩短；真人之间在聊天时不插话；被 @ 的回复总留一个名额；同一个人说完有冷却，同一句话近期不重复。
  - **AI**：开启 `ai.enabled` 后，回复真人和冷场闲聊由 AI 决定谁说、说什么，同样受限流控制。默认接 DeepSeek（`deepseek-chat`），通义千问、Kimi、智谱、豆包、OpenAI、中转站、本地 Ollama 等 OpenAI 格式的接口改 `base_url` 和 `model` 即可，也支持 Claude 的接口（`format: anthropic`）。有每分钟和每天的调用上限；超时、出错或用完次数时自动改用语料。AI 按每个测试假人的性格说话，不承诺给东西、不冒充管理员，有人问是不是机器人时不回答。
  - **接入聊天插件**：`send_mode: auto` 检测到 TrChat、ChatControl、EssentialsChat、CarbonChat 等聊天插件时，测试假人的话和真人一样走服务器的聊天流程，由聊天插件排版、分频道、跨服转发；被登录或禁言插件拦下时改用 `format` 发出。TrChat 这类自己重发聊天的插件取消了原版聊天时，真人的消息照样能被测试假人听到（`include_cancelled_chat`）。
  - 新指令 `/afp test say`、`/afp test chat`、`/afp test ai`；`/afp test info` 显示性格和会不会说话。

- **自动收割**：开启挖掘、背包里有锄头时，假人收割正前方一格成熟的小麦、胡萝卜、马铃薯、甜菜根、下界疣和可可豆，没成熟的不动；同时开着自动种植时，收完马上补种。快捷栏第 3~9 格放了小麦（或小麦种子）、胡萝卜等时只收这几种，没放时收所有成熟的农作物，锄头能挖的方块（树叶、干草块等）也会挖。
- **重启后自动召唤**：正常关服（`stop`）时本服正在运行的假人，开服后在原来的位置召唤回来，不收费，背包、设置、生命和饱食度保留。由 `config.yml` 的 `slots.restore_after_restart` 控制，默认开启；服务器崩溃时来不及记录，需要重新召唤。主人的假人数被调低、本服在线上限已满，或假人已经在其他子服运行时不召唤，原因会写在后台日志里。
- **管理员传送**：`/afp atp <名字>` 传送到任意玩家的假人，名字就是 TAB 里显示的假人名字（不含前缀，不分大小写，可以按 Tab 补全）；也可以写 `/afp atp <玩家> <编号>`。假人在其他子服运行时把你送过去。没有等待和冷却。

改进

- 自动钓鱼按原版钓鱼，CustomFishing 等钓鱼插件不会接管假人的鱼钩（这些插件的小游戏假人玩不了）；收竿被其他插件取消时，假人直接收回鱼线再重抛，鱼线不会一直挂着。
- 挖掘样本改为快捷栏第 3~9 格。第 1、2 格留给工具和要放置的东西，放在这两格的方块不再限制挖掘。
- 自动放置、种植时，主手拿着工具就把要放的东西换到副手（副手原来的东西换回背包），不再和工具来回换。
- 挖掘、收割掉下来的东西直接落到假人脚下，不会弹到拾取范围外。
- 服务器上的语言文件缺少某条消息时，改用插件自带的文字，不会再直接显示消息名（如 `inventory_not_found`）。

升级须知

- 数据库会自动升级（新增 `restores` 表和测试假人档案表），不用手动操作。
- `tab_test.yml` 和 `tab_chat.yml` 第一次启动时自动生成。测试假人聊天默认开启、AI 默认关闭；要用 AI，在 `tab_chat.yml` 里设置 `ai.enabled: true` 和 `api_key`，执行 `/afp reload`，再用 `/afp test ai` 测试。开启 AI 后，真人的聊天内容和最近的聊天记录会发给填写的 AI 服务商。
- `send_mode` 为 `chat`（或 `auto` 且装了聊天插件）时，测试假人第一次说话会在 LuckPerms 里建一个用户并加入它的权限组，聊天插件才能显示前缀。不想这样就把 `send_mode` 改成 `format`，并把 `format` 改成和服务器聊天格式一样。
- 测试假人现在默认显示进服、退服提示；不想显示就在 `tab_test.yml` 里设 `join.messages: false`。
- `config.yml` 不用改：没有 `slots.restore_after_restart` 时按开启处理。想关闭就在 `slots` 下加一行 `restore_after_restart: false`。
- 删除 `menus/settings.yml` 后执行 `/afp reload`，才会出现新的挖掘和放置说明。
- 以前把挖掘样本放在快捷栏第 1、2 格的，要挪到第 3~9 格。
- 想在 `/afp admin help` 里看到 `atp`、在 `/afp test` 的用法里看到新指令，删除 `lang/zh_CN.yml`（或 `en_US.yml`）后执行 `/afp reload`；新增的提示消息不删文件也能正常显示。

### 1.0.2

新增

- **领地兼容**：在 Dominion、Residence 的领地里，假人和主人的权限相同。主人自己的领地、主人有权限的别人的领地都能干活，不用单独添加假人；只继承领地里的成员和权限设置，不继承主人的权限节点。其他按玩家 UUID 判断权限的领地插件可以加到 `config.yml` 的 `claims.plugins`。
- **自动钓鱼**：行为设置中开启后，假人主手换上鱼竿，尽量平视抛向正前方的水（大片水面不低头，水离得近时只低到刚好能落进去；会避开岸边的方块和栅栏，一格宽的水沟也能钓），咬钩就收竿，钓到的东西直接进背包。浮漂连续 3 秒不在水里会收回重抛；鱼竿快坏时停用。钓鱼时不挖掘、攻击和放置。
- **自动种植**：「放置方块」设定为树苗、种子等植物时改为种植，种在正前方一格的地面上（与脚下平齐或高一格），作物要耕地。高两格不种。植物可以放在主手、副手或背包里；有人站在前方也照常种植；同时开着挖掘时，这格地面不会被挖掉。
- **盔甲架横扫**：假人会攻击盔甲架，拿剑对着盔甲架就能横扫刷怪；攻击间隔不少于 20 tick，盔甲架只会晃动，不会被打碎。
- **主菜单显示生命和饱食度**：假人在本服运行时，假人按钮显示当前生命和饱食度（新占位符 `%health%`、`%food%`）。
- **管理员查看背包**：`/afp b <玩家> <编号>` 打开任意玩家假人的背包，可以取放物品。
- **禁止本服召唤**：`config.yml` 中 `slots.max_active_server` 设为 `0` 时，本服不能召唤假人，也不能把其他子服的假人召回本服。

改进

- 需要输入的提示（攻击间隔、工作方向）60 秒内有效，可以点击提示里的 **[取消]**；输入的内容不会再被聊天插件发到聊天里。
- `/afp test` 的虚拟玩家在 TAB 中显示 `luckperms.group` 权限组的前缀，跨服时也一样。
- 经验修补正常生效：拿在手上和穿在身上的装备会用经验球修补。
- 假人站在耕地、灵魂沙、泥巴、土径等接近一格高的方块上时，挖掘和种植的高度按脚所在的那一格算，不会再去挖脚下这层地面。

升级须知
